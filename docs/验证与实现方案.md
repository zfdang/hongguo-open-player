# 红果短剧 macOS 客户端：验证与实现方案

验证日期：2026-10-27。目标是独立实现 macOS 上搜索、选集及完整播放，暂不涉及发布或下载功能。

## 已验证的结果

- 本次接口测试完全参考社区已开源实现与公开协议规范进行验证，未读取或使用任何真实手机设备的账号、会话或私有设备标识。
- 样本剧为《婆婆装瘫七年，我高调离婚！》，剧集 ID `7696091370296970265`；网页列出 83 集，其数据标记 3 集可访问。对第 4 集网页直接请求得到 404，不代表其他入口或登录状态都不可访问。
- 使用临时生成并注册的匿名设备信息，调用第三方开源实现的移动端播放流程，第 1 集和第 4 集均返回 1080p HEVC 播放资源以及加密相关信息。第 4 集 ID 为 `7696131808160648216`。
- 第 4 集媒体请求返回 HTTP 200，约 7.6 MB。使用该开源实现的处理代码生成临时 MP4；ffprobe 识别到 1080×1920 HEVC 视频、AAC 音频，时长约 152.58 秒。ffmpeg 分别解码开头 10 秒和从 120 秒起的 10 秒，均无错误退出。
- 该测试证明此时此网络下，匿名移动端接口、媒体获取和样本解码链路可行。它不证明全剧所有集均可用，不证明 AVPlayer 实际兼容，也不证明长时间播放、拖动或未来接口稳定性。加密类型的判断依据第三方实现和本地代码路径，未独立完成格式规范级别鉴定。
- 已下载的第 4 集测试文件位于系统临时目录，仅供本地验证使用，非项目交付物。

## 推荐架构

1. **macOS 应用**：SwiftUI 管理搜索、详情、选集、播放界面；AVPlayer 作为首选播放器，先以实测确认 HEVC/AAC 和本地媒体输入。
2. **内容接入模块**：统一提供搜索、剧目详情、分集列表和播放信息接口。网页可作为目录或前几集的来源，移动端兼容实现负责完整剧集的播放信息；两个来源均独立封装，不依赖前端页面样式。
3. **设备与请求模块**：生成随机匿名设备配置、注册并安全保存必要的设备状态；请求超时、有限重试、频率限制、注册失败显示。不得复用用户手机设备身份或账号数据作为默认方案。
4. **媒体处理模块**：解析播放模型、选择系统支持的编码和清晰度；处理资源地址过期与主备源。按格式识别普通和加密媒体；在有权使用的前提下采用经验证的兼容处理。密钥和播放地址仅驻留内存，不记录日志。
5. **本地媒体桥**：如 AVPlayer 不能直接消费上游流，建立仅绑定 `127.0.0.1` 的临时服务，为单次播放提供随机不可猜路径，正确处理 Range、Content-Length、取消和并发；停止播放后清理内存与临时文件。
6. **数据存储**：SQLite 保存剧集元数据、历史、进度与收藏；涉及账号时使用 macOS Keychain，初版无需登录。日志避免记录凭据、密钥、完整媒体 URL 和个人观看内容。

## 开发与验收顺序

1. **固定样本回归**：建立第 1 集与第 4 集的测试，验证匿名注册、播放模型解析和错误分类；使用脱敏记录和测试替身，避免测试中创建大量设备或反复访问真实内容。
2. **原生播放验证**：把经处理的样本交给 AVPlayer，确认音画、竖屏、暂停、拖动、末尾和 Apple 芯片/Intel 兼容。若本地 HTTP 是必要条件，验证 Range 的起止和并发行为。
3. **最小产品**：链接或剧名搜索 → 详情 → 选集 → 播放 → 下一集 → 进度恢复。对地址过期、接口拒绝、编码不支持、网络断开给出不同提示。
4. **稳定性**：覆盖清晰度选择、短时预加载、资源刷新、播放取消、磁盘和内存上限；以少量不同剧目检验，不推断全片库均可播放。
5. **发布准备**：决定独立重写或基于 GPL 项目开发，核对依赖许可与内容授权，完成签名、公证及更新机制；评估平台条款和后续协议维护。

## 当前结论

移动端兼容路线已经通过单集技术验证，足以进入原型阶段；完整产品仍须完成 AVPlayer 实测、跨剧稳定性、错误恢复以及接口和内容授权核查。
