# 综合审查落实记录

本次根据综合报告和 `reviews/` 中的安全、流媒体、桌面架构及交互子报告核查并实施修改。原报告的评分、内存峰值和固定倍数不作为本项目的性能承诺。

## 流媒体与内存

- 默认走真正的按需 Range 解密：先探测顶层 box 并读取 moov，然后只下载播放器请求的媒体范围。CENC 样本跨 Range、跨 AES 块时按样本 nonce 和块计数定位密钥流。
- 单次媒体读取限制为 512 KiB，响应通过 Node 流管道施加背压；同时最多服务三个媒体响应。下一集只预取元数据，前台播放会取消后台预取。
- 元数据单文件最多 4 MiB，聚合样本数最多 100,000；元数据缓存按估算预算限制为 32 MiB 和最多八项。支持的远端文件最大为 1 GiB。估算缓存预算不是整个进程的 RSS 上限。
- 不支持 Range 的 CDN 保留整集兼容路径：单个下载最大 64 MiB，完整媒体缓存最多 128 MiB，同时只运行一个完整下载任务，最多八个待处理任务。相同 vid/清晰度共用任务，最后一个消费者断开时取消；前台任务优先于后台任务。
- CDN 竞速最多同时启动两个源，失败分片批次先取消再回退。所有媒体请求使用公网地址防护、受限的复用连接池，并禁止重定向。
- 修复小文件最后一片起点越界。传入的 quality 会参与取址及缓存键。
- AES-CTR 改为原生 crypto 实现。MP4 重建会将 moov 移到媒体之前，重定位 stco/co64；保护音频从 frma 读取实际编码。
- MP4 样本表、偏移和数量先校验；整集解密不修改调用者传入的缓冲。子样本加密、16 字节 IV、外置辅助加密信息和碎片化 MP4 尚不支持，明确拒绝，而非输出未正确解密的视频。

## 播放交互

- 全屏 Escape 优先退出全屏，并保护紧随原生 fullscreenchange 的按键；文本输入和可编辑区域不触发播放快捷键。剧场按钮与滑块的焦点取舍见 [播放器交互设计](播放器交互设计.md)。
- 进度条支持指针拖动，提供悬浮时间预览及 24px 命中区域；剧场中的键盘操作以播放快捷键为优先。
- 提高音量会解除真实媒体静音；已看分集按实际播放记录保存、恢复，不把跳过的分集推断为已看。
- 普通分类退出播放时保留原列表和滚动位置；加载状态由媒体事件解除，避免刚请求视频就提前隐藏缓冲提示。
- 用非阻塞提示替代 alert，补充快捷键反馈、解码错误提示、系统媒体操作与剧集标题。
- 增加窄窗口断点、选集折叠、目录骨架屏、减弱动画选项和更清晰的次要文字；浏览器不再保留 macOS 原生标题栏留白。
- 收藏请求只发送摘要信息，避免长剧分集列表超过 64 KiB 请求限制；保存失败会显示提示。

## 桌面、安全及数据

- Windows 图标纳入发布包；启用 Windows 标题栏叠加，预留系统按钮区域并补充文件/退出菜单。
- 窗口创建期间复用同一个 Promise；启动失败显示可见错误。导航和服务端重定向均校验来源，畸形 URL 也会被阻止。
- 退出时停止预加载和媒体任务、关闭长连接，等待已接收的存储写入结束。
- 数据写入使用串行异步队列、唯一临时文件及原子替换；Windows 文件占用失败执行有上限的退避重试。保留上一份有效状态为 `.bak`，主文件损坏时恢复；两份均损坏时保留文件并拒绝覆盖。
- API 和视频需通过首页建立随机本地会话，使用 HttpOnly / SameSite=Strict Cookie，不在媒体 URL 中传递凭据；原有 Host/Origin/Fetch Metadata 校验继续生效。这不用于阻止同一用户的本地程序访问服务。
- 增加 CSP、禁止嵌入、禁止 MIME 嗅探和无来源引用头。当前 Vue 模板运行时需要 `unsafe-eval`，不能直接套用报告中会破坏界面的严格脚本策略。
- API 对外返回受控消息，移除对未包含的 custom/hema/xifan 适配器的引用。
- 正式发布仅由 v* 标签或手动操作触发；普通提交继续验证，避免每个主分支提交都占用原生构建节点并创建正式版本。

## 验证

- 本地 `npm test`：34 项离线回归及七项真实接口端到端验证通过。
- 新增合成加密 MP4 夹具，验证完整/非完整 AES 块、随机范围解密与整集结果逐字节一致；2 MiB 样本只读取不足 4 KiB 的元数据即可准备响应。测试同时覆盖取消、写锁恢复、备份恢复、平台窗口选项、快捷键及静音状态。
- 在浏览器实际播放 1080×1920 视频，验证 960 CSS px 宽度、选集折叠和跳转到 45 秒后的播放。
- 本机五次合成 8 MiB 样本中位数：旧手写 CTR 样本处理约 64.4 ms，新原生整份 MP4 解密约 5.2 ms。两者计时范围不同，且未模拟每一轨道/设备，仅用作本次局部优化的佐证，不推广为固定倍率或内存下降百分比。
- 修改后的 JavaScript 语法检查、工作流 YAML 解析与 diff 空白检查通过。跨平台 CI 和在线验证在 PR 中运行。

## 保留的演进项与验证边界

- macOS 签名、公证和 Hardened Runtime 需要开发者证书及相应权限，不能仅修改两个布尔值就宣称完成；当前无签名发行配置保留。
- 尚未新增专用的子样本/16 字节 IV/碎片化 MP4 解码支持，也未承诺所有来源及解码器兼容。co64 和受保护音频处理应继续补充真实样本覆盖。
- 目录卡片一键收藏、完整的媒体键 seek 操作及 GPU 崩溃后的自动恢复仍可后续扩展；本次提供了剧场收藏、基本系统媒体操作和解码分类提示。
- 本次验证浏览器真实播放及三平台窗口逻辑；新的 Windows 标题栏、原生安装包和签名行为仍需对应设备或发布流程验证。
