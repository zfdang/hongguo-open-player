红果开源播放器

v1.2.0 · 原生桌面客户端

一款基于 Electron、Node.js 与 Vue 打造的开源跨平台红果短剧原生桌面播放客户端。 无需安装安卓模拟器，内置流媒体解密与本地代理，提供剧目检索、演员榜单、沉浸式影院观影与本地进度记忆。

🎬 实时流式解密 🚀 免安卓模拟器 📱 沉浸式自适应画幅 🌟 剧星榜与演员主页 ⚡ 智能节点加速
